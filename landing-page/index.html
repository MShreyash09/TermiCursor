Total Privacy

Zero cloud. Zero telemetry. Every model runs on your machine. Your source code never touches the internet.

Flexible Models

Choose your LLM — Qwen, LLaMA, Mistral via Ollama, or use cloud Groq. Switch anytime from Settings.

Syntax-Aware Parsing

Code is chunked using language-specific AST splitters for Python, JavaScript, and TypeScript — keeping functions and classes intact.

Persistent Memory

Powered by Mem0 — TermiCursor remembers your preferences, coding patterns, and prior context across sessions.

File Operations

Ask the AI to create, edit, or delete files directly in your project. It writes code and saves it for you automatically.

How It Works

Two-phase intelligence pipeline

TermiCursor first indexes your codebase into a local vector database, then uses it for intelligent retrieval.

Phase 1 — Ingestion
01

Scan

Recursively finds .py, .js, .ts, .tsx, .jsx files in your project

→
02

Parse

Language-aware chunking preserves functions and class boundaries

→
03

Embed

nomic-embed-text generates semantic vectors for each chunk

→
04

Store

Vectors indexed in a local, path-isolated Qdrant collection

Phase 2 — Query
01

Question

Type your question in the integrated chat panel

→
02

Retrieve

Top-k most semantically relevant code chunks are fetched

→
03

Augment

Code context + memory + system persona assembled into prompt

→
04

Generate

Local LLM streams a precise, context-aware answer
